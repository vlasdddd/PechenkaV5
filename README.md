# PechenkaV5

Автоматическое обнаружение объектов на экране и нажатие на них. Для распознавания используется YOLO-модель в формате ONNX с инференсом на CPU.

## Возможности

- Захват экрана с помощью `mss`.
- Обнаружение объектов YOLO-моделью через ONNX Runtime.
- Клики мышью через `pyautogui`.
- Пауза и возобновление работы клавишей **Space**.
- Порог уверенности обнаружения — `0.7`.
- Пауза `pyautogui` между действиями — `0.005` секунды.

## Последовательность действий

Приложение выполняет следующие действия:

1. Ищет объект `game` и нажимает на него до 10 раз. Таймаут поиска — 1 секунда.
2. Ищет объект `taper` и нажимает на него один раз. Таймаут поиска — 1 секунда.
3. Ищет объект `reklama` и нажимает на него один раз. Таймаут поиска — 1 секунда.

Нажмите **Space**, чтобы приостановить или возобновить работу приложения.
